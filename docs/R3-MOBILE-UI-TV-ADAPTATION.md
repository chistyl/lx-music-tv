# LX Music TV R3 — 行動版原生介面適配規格

## 本分支定位

本專案以官方 **LX Music 移動版**（https://github.com/lyswhut/lx-music-mobile）作為功能與視覺設計的主要依據，將其完整體驗適配至 Android TV。不是沿用既有 TV 專案的客製化主題，也不是重新發明一套播放器品牌介面。

官方移動版是產品行為、資訊架構、視覺語言、功能名稱、圖示、色彩及互動流程的參考基準。既有 TV 專案僅作為 Android TV 技術底座與可重用功能程式碼來源；若現有 UI 與官方移動版不同，應以移動版為準重新調整。

## 視覺與互動原則

1. 保留官方移動版的整體視覺識別、配色、圖示風格、元件語言、資訊層級、頁面名稱與功能組織。
2. 不採用 Apple Music、Apple TV、第三方 TV 音樂播放器或本專案舊版自行設計的視覺風格。
3. 不以手機畫面直接等比例放大；只為 16:9 電視重新配置欄寬、卡片尺寸、留白、字級與內容密度。
4. 所有可操作元件必須可由標準 Android TV 遙控器操作：方向鍵移動、確認鍵執行、返回鍵返回；焦點狀態清楚且符合頁面閱讀順序。
5. 搜尋、音源匯入、設定等文字輸入流程須提供 TV 遙控器可完成的操作方式；既有手機/Web 輔助方式可保留。
6. 不得因 TV 版適配而刪除或簡化原版已有的音樂功能。若因平台限制無法完全一致，需記錄原因及替代操作。

## 功能保留基準

以官方移動版功能及使用流程為基準，逐項盤點並保留可移植功能，包括但不限於：

- 搜尋、搜尋歷史、搜尋建議及結果操作
- 播放佇列、播放模式、上一首／下一首、進度控制
- 歌詞顯示及同步
- 自訂音源匯入、管理與執行
- 歌曲與歌單收藏、播放歷史
- 本地音樂及快取管理（依 TV 裝置能力適配）
- 播放相關設定、介面設定及資料管理

不得把目前 TV 專案 README 所列功能視為已完整等同官方移動版；應建立功能對照表，逐項確認實作、測試與差異。

## 音源規則

1. 移除使用者手動設定的音源平台綁定、平台白名單及平台限定選項。
2. 每個 JS 音源只依其腳本初始化時自行宣告的 `sources/platforms` 能力判斷支援平台。
3. 搜尋或播放某平台時，只呼叫明確宣告支援該平台的音源。
4. 多個音源支援同一平台時，依使用者設定／啟用優先順序逐一嘗試；失敗時可切換下一個支援該平台的音源。
5. 不得把「同一音源解析失敗」解讀成可以任意改用其他平台 ID。平台支援仍以腳本宣告為準。
6. 音源管理介面只呈現音源自身宣告的平台資訊作為唯讀能力資訊，不提供人工勾選綁定。

## 更新機制移除

完全移除應用程式內的更新檢查、版本更新提示、下載更新入口及自動更新流程。不得影響音源腳本匯入或使用者自行安裝 APK。

## Android TV 相容性與驗收

- 最低支援 Android 9（API 28），除非專案既有明確相容性決策另有記錄。
- 主要版面以 16:9 電視為目標，並檢查常見 720p／1080p 顯示。
- 全流程僅使用遙控器即可完成主要操作。
- 焦點不可遺失、不可被畫面外元件攔截，返回鍵行為一致。
- 驗證背景播放、螢幕關閉／返回桌面後的播放狀態及媒體按鍵。
- 完成繁體中文（台灣）介面校對。
- 建置成功後才可標記 APK 可交付；交付包含 APK 與完整原始碼 ZIP。
